# 🎵 Music Player

A simple, responsive web-based music player.

## 🚀 Features
* Play, pause, and skip tracks.
* Interactive progress bar.
* Mobile-friendly design.

## 🛠️ Tech Stack
* HTML5
* CSS3
* JavaScript (Vanilla)

## 💻 How to Run
1. Clone the repository.
2. Open `index.html` in your browser.
